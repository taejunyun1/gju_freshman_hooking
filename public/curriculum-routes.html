PHOTO:NEXT / FOUR-YEAR CURRICULUM

관심 분야에서 시작하는 1~4학년 제작 루트

1·2학년에는 사진·영상 제작의 공통 기반을 익히고, 3·4학년에는 관심 분야에 맞춰 프로젝트와 포트폴리오를 확장합니다.

CURRICULUM ROUTE

영상+AI

촬영·편집·AI 이미지와 영상 기술을 결합해 콘텐츠를 제작하는 경로입니다.

1Y · 사진·영상 언어 기초

공통 기반

  • 기초사진실기
  • 영상 에세이 메이킹
  • 영상 프레임과 컷

카메라·프레이밍·촬영의 기초를 익힙니다.

2Y · 제작·후반작업 확장

공통 기반

  • 사진커뮤니케이션
  • 다큐멘터리 메이킹&쇼케이스

촬영·편집·발표의 흐름을 경험합니다.

3Y · 전공심화·프로젝트

심화 교과

  • 영상 인터뷰 내러티브 워크숍
  • 영상 드론 콘텐츠 워크숍
  • 영상 콘텐츠 크리에이터 워크숍

인터뷰·드론·크리에이터 작업으로 영상 제작 언어를 확장합니다.

4Y · 캡스톤·포트폴리오

제작 단계

  • 영상·AI 통합 포트폴리오
  • 졸업전시·캡스톤 제작

개별 교과목이 아닌 통합 제작 단계로, 나만의 영상·AI 작업을 완성합니다.

CURRICULUM ROUTE

예술사진

사진의 개념과 장소, 데이터를 탐구해 개인 작업과 전시로 발전시키는 경로입니다.

3Y · 전공심화·프로젝트

심화 교과

  • 사물,데이터,이미지 워크숍
  • 사진과 장소 그리고 콘텍스트 워크숍

사물·장소·데이터를 바탕으로 사진의 주제와 형식을 탐구합니다.

4Y · 캡스톤·포트폴리오

심화 교과

  • 예술창작 프로젝트 세미나
  • 예술창작 프로젝트 랩

연구와 제작을 연결해 전시·포트폴리오로 발전시킵니다.

CURRICULUM ROUTE

다큐멘터리

기록의 시선을 심화해 장기 프로젝트와 포트폴리오로 완성합니다.

CURRICULUM ROUTE

광고사진

패션·제품·뷰티·브랜드 이미지를 기획하고 조명·촬영으로 구현하는 경로입니다.

기획부터 촬영·후반작업까지 상업 포트폴리오를 완성합니다.
