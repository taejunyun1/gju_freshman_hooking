## 3. 플랫폼 표시 원칙

- 기자재·시설은 결과의 메인 콘텐츠가 아니다. 학생의 관심사가 4년 교과·프로젝트·결과물·진로로 이어지는 주 경로를 먼저 보여주고, 장비·시설은 해당 학습과 제작이 실제로 가능하다는 보조 근거로 관련 단계 아래에 붙인다.
- 첫 화면에는 시설 1개, 카메라 바디 1개, 렌즈 1개를 이 순서로 우선 표시한다. 없는 유형을 다른 장비로 대체하지 않으며, “학과 기반 더보기”에서 남은 근거를 합계 최대 4개까지 노출한다.
- 장비 보유 자체를 진로나 성과의 충분조건처럼 표현하지 않는다. 관심사와 교과·프로젝트의 연결이 먼저 성립해야 하며, 장비·시설은 그 경로를 수행할 수 있는 필요 기반 중 하나로 설명한다.
- 결과 화면은 개별 관리 코드를 144개의 카드로 나열하지 않고, 같은 위치의 동일 모델을 하나의 기자재 자원으로 묶어 수량을 표시한다.
- 관리자 데이터는 144개 개별 항목을 모두 보존해 위치, 코드, 이용 구분, 상태와 비고를 추적한다.
- 학생 추천 카드는 장비명, 위치, 확인된 수량, 이용 구분, 연결 관심사, 연결 교과, 기준일을 표시한다.
- `문의 전용`은 예약 가능으로 바꾸어 표현하지 않고 판타지랩 조교 또는 학과 문의가 필요하다고 안내한다.
- 중복 코드는 `duplicate_code`, 미확인 명칭은 `unidentified`, 수량 확인 항목은 `quantity_check`로 두고 정확한 모델·수량·코드가 확인될 때까지 개별 공개 추천에서 제외한다.
- 실제 예약 링크는 `https://gjureserve.co.kr`을 사용하고 예약 가능 여부를 PHOTO:NEXT가 보장하지 않는다.
- 기자재 사진은 사용 권한, 대체 텍스트와 실제 모델 일치가 확인된 파일만 공개한다.
