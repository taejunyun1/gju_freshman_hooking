## 1. 운영 원칙

광주대학교 사진영상학과는 조대연, 윤태준, 김사라 전임교원을 중심으로 사진·영상 교육과 학생 진로지도를 운영한다. 세 전임교원은 각각 포토커뮤니케이션, 현대예술·영상, 다큐멘터리·아카이브 분야를 담당한다.

플랫폼은 학생에게 교수 한 명을 자동으로 확정 배정하지 않는다. 학생의 관심 분야를 분석해 전임교원 중 총괄 상담교수 1명과 예비 전임교원 1명을 추천하고, 세부 실무교육이나 프로젝트가 필요한 경우 겸임교원·실무전문가를 최대 2명까지 함께 안내한다. 실제 상담 담당자는 관리자가 최종 배정한다.

```text
학생 관심사 분석
      |
      v
전임교원 총괄 추천 1명 + 예비 1명
      |
      v
필요 시 겸임교원·실무전문가 0–2명 연계
      |
      v
관리자 최종 상담교수 배정
```

## 2. 공개와 데이터 관리 기준

- 교수 이름, 직위, 소개, 전문분야, 교육·프로젝트·진로, 학력·경력, 추천 태그는 공개 콘텐츠로 사용할 수 있다.
- 연구실, 전화, 이메일, 웹사이트는 각 필드별 공개 상태를 관리하며 학과 확인 후 학생 화면에 노출한다.
- 교수 사진은 사용 권한과 공개 동의를 확인한 파일만 사용한다.
- 이메일과 전화번호를 분석 이벤트나 오류 로그에 기록하지 않는다.
- 프로필 변경은 관리자 미리보기와 게시 승인을 거친다.
- 전문 연계는 전문교원 프로필과 함께 `draft`에서 미리 작성할 수 있지만, 게시 검증을 거쳐 `active`가 되기 전까지 `draft`·`archived` 교수와 연계는 학생 추천에 사용하지 않는다.
- 경력과 개설 교과처럼 시간에 따라 변하는 정보는 `source_date`와 `last_verified_at`을 저장한다.
- 이 가이드의 원문과 구조화 seed가 다르면 이 가이드를 우선 기준으로 삼고 관리자 승인 이력으로 변경을 추적한다.

## 6. 1차 총괄 상담 추천 규칙

전임교원만 1차 총괄 추천 후보가 된다.

### 김사라 교수 우선 태그

- 지역문화 기록
- 사진아카이브
- 공공기관 프로젝트
- 문화기관 콘텐츠
- 인터뷰와 현장조사

다큐멘터리 관심이 사회·사람·포토스토리에 가까우면 조대연 교수를, 지역·기관·아카이브·현장조사에 가까우면 김사라 교수를 우선한다. 두 방향의 점수가 같으면 두 교수를 총괄·예비 순서로 함께 보여주고 현재 상담 용량으로 1순위를 정한다.

광고·패션·제품사진처럼 겸임교원의 세부 전문성이 가장 높고 특정 전임교원 총괄이 정해지지 않은 경우, 학생의 나머지 관심 태그와 현재 상담 용량으로 전임교원 총괄·예비를 정하고 곽동욱 겸임교수를 전문 연계로 반드시 표시한다. 플랫폼은 근거 없이 특정 전임교원을 광고사진 전문가로 표현하지 않는다.

## 7. 2차 전문분야 연계 규칙

- 영상촬영·드론·VR·360 → 윤태준 교수 총괄 우선, 박재웅 겸임교수 연계
- 전시기획·큐레이팅·예술이론 → 윤태준 교수 총괄 우선, 정철호 겸임교수 연계
- 광고·패션·제품·뷰티·브랜드·스튜디오 → 전임교원 총괄, 곽동욱 겸임교수 연계
- 다큐멘터리·사회·지역·아카이브가 함께 높음 → 조대연·김사라 교수 공동 연계 가능

전문 연계는 관련 태그 적합도가 50점 이상일 때 최대 2명까지 표시한다. 동일한 전문분야의 연계 교원이 여러 명이면 점수, 관리자 우선순위, 이름 순으로 결정한다.

함께 연결되는 전문분야
박재웅 겸임교수 · 드론·VR·영상콘텐츠
정철호 겸임교수 · 전시기획·큐레이팅

“배정 완료”나 “담당 교수”라고 표현하지 않는다. 학생 결과에는 “추천 총괄교수”, “예비 상담교수”, “함께 연결되는 전문분야”를 사용하고, 관리자가 실제 배정한 뒤 상담 화면에서만 “담당 교수”로 표시한다.

### 교수 기본 필드

### 추천 태그 필드

```text
faculty_id
tag_key
tag_label
category: track | activity | result | career | specialist
weight: 0..3
is_primary
```

최초 seed의 가중치는 다음 규칙으로 만든다.

- 각 교수의 “플랫폼 추천 태그”: 해당 전문 category에서 3, `is_primary = true`
- “주요 교육·지도 분야”에만 있는 태그: activity에서 2
- “학생 연계 프로젝트”에서 추출한 결과물 태그: result에서 2
- “연계 가능한 진로”의 직무 태그: career에서 3
- 겸임교원의 플랫폼 추천 태그: specialist에서 3
- 명시된 전임–겸임 연계 조합: `priority = 100`

한 태그가 여러 category에 해당하면 행을 분리해 각 맥락의 점수를 보존한다. seed 생성 후 관리자가 미리보기에서 교수별 상위 매칭 태그와 대표 학생 시나리오를 확인하고 게시한다.

### 전문 연계 필드

```text
primary_faculty_id
specialist_faculty_id
tag_key
priority
explanation_template
```

`primary_faculty_id`가 비어 있으면 특정 전임교원을 광고사진 전문가로 단정하지 않고 모든 활성 전임 총괄교수와 연결 가능한 학과 공통 전문 연계를 뜻한다. 곽동욱 겸임교수의 광고·패션·제품·브랜드 연계가 이 규칙을 사용한다.

추천 결과 스냅샷에는 교수 ID뿐 아니라 당시 표시 이름, 직위, 전문분야, 추천 이유, 역할을 함께 저장해 과거 결과가 프로필 변경으로 달라지지 않게 한다.
