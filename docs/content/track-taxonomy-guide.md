# PHOTO:NEXT 관심사·전공 트랙 운영 가이드

- 기준일: 2026-07-14
- 상태: 운영 기준안
- 적용 범위: 관심사 평가, 결과 화면, 교수 추천, 관리자 미리보기, 짧은 진로 제안
- 근거: `shared/types/domain.ts`, `supabase/seed/assessment-options.json`, `supabase/seed/curriculum-2026.json`, `supabase/seed/faculty-2026.json`, `docs/content/faculty-directory-guide.md`

## 1. 목적

이 가이드는 학생이 선택한 관심사가 광주대학교 사진영상미디어학과의 교과, 프로젝트, 교수진, 진로 방향으로 어떻게 이어지는지 일관되게 설명하기 위한 운영 기준이다.

플랫폼의 전공 방향은 아래 네 개만 사용한다. 교과·프로젝트·교수진·장비·시설이 새 트랙을 만들지 않으며, 관리자도 별도 트랙 키나 임의 점수를 추가하지 않는다.

| 고정 키 | 학생 표시명 | 범위 |
|---|---|---|
| `documentary` | 다큐멘터리 사진 | 사람·사회·지역·기관을 조사하고 사진·영상·텍스트로 기록하는 방향 |
| `art_photo` | 예술사진 | 개인 주제, 현대예술, 사진·영상·설치, 전시와 포트폴리오로 발전시키는 방향 |
| `commercial` | 광고사진 | 제품·패션·뷰티·브랜드 이미지를 조명과 스튜디오 실무로 완성하는 방향 |
| `video` | 영상과 기술(AI·편집·드론) | 영상촬영, 내러티브, 편집·색보정, AI 이미지·영상, 드론과 디지털 이미지 기술을 활용하는 방향 |

`AI`, `편집`, `드론`, `기술적 이미지`는 다섯 번째 전공 트랙이 아니다. 모두 `video` 안에서 구체적인 관심 태그와 교과 근거로 설명한다. 다만 학생이 AI 이미지나 영상 기술을 개인 주제, 설치, 전시로 발전시키려는 경우에는 `art_photo`와 함께 보여줄 수 있다.

## 3. 관심사에서 결과까지 연결하는 순서

1. 평가 카탈로그의 선택지로 네 트랙 점수와 관심 태그를 계산한다.
2. 상위 트랙과 관심 태그에 맞는 게시 교과와 프로젝트를 찾는다.
3. 교과와 프로젝트가 어떤 결과물·포트폴리오로 이어지는지 설명한다.
4. 전임교원 중 총괄 1명과 예비 1명을 추천하고, 필요한 전문 교원을 최대 2명까지 연결한다.
5. 교수진 가이드에 확인된 진로 또는 학생이 선택한 진로 방향을 연결한다.
6. 마지막에 이 학습을 실제로 지원하는 검증된 장비·시설 근거를 간결하게 덧붙인다.

결과 화면은 “트랙 이름 → 장비 목록”으로 바로 점프하지 않는다. 학생의 선택을 교과와 제작 경험, 교수진, 결과물·진로로 먼저 연결한 뒤 장비·시설을 실현 가능성을 보여주는 보조 근거로 사용한다.

## 4. 중첩 분류 원칙

### 4.1 한 학생에게 여러 트랙이 함께 보일 수 있다

네 트랙은 상호 배타적인 전공 배정이 아니다. 고정 점수 산식의 순위를 유지하고, 1순위는 주 방향, 그다음 순위와 관심 태그는 융합 방향을 설명하는 데 사용한다. 운영자가 결과에 맞추기 위해 점수나 순위를 다시 쓰지 않는다.

### 4.2 공통 관심은 결과물의 목적을 보고 구분한다

- 인터뷰와 영상이 사회·사람·지역의 기록을 위한 것이면 `documentary` 근거를 우선하고, 촬영·편집·쇼릴 제작이 중심이면 `video` 근거를 함께 보여준다.
- 사진·영상·AI를 개인 주제, 현대예술, 설치, 전시로 발전시키면 `art_photo`와 `video`를 함께 보여줄 수 있다.
- 브랜드 홍보영상은 `commercial`과 `video`, 스튜디오 인물 촬영은 `commercial`과 `art_photo`가 함께 나타날 수 있다.
- 포토북과 전시는 `documentary`와 `art_photo` 모두의 결과물이 될 수 있으므로, 학생이 선택한 기록·사회 태그와 개인창작·전시 태그로 이유를 구분한다.

### 4.3 다큐멘터리는 총괄 역할을 세분화한다

- 사회·사람·포토스토리·포토커뮤니케이션: 조대연 교수 우선
- 지역문화·공공기관·문화기관·아카이브·현장조사: 김사라 교수 우선
- 두 방향이 함께 높으면 두 교수를 총괄·예비로 함께 보여주고 상담 용량으로 순서를 정한다.

### 4.4 광고사진은 전임 총괄을 임의로 전문화하지 않는다

광고·패션·제품사진 관심이 높아도 특정 전임교원을 광고사진 전문가로 표현하지 않는다. 전임 총괄은 학생의 다른 관심 태그와 상담 용량으로 정하고, 곽동욱 겸임교수를 전문 연계로 표시한다.

### 4.5 윤태준 교수의 두 축을 모두 보존한다

윤태준 교수의 전문분야는 “현대예술·예술사진·영상·AI·기술적 이미지”이다. 예술사진 결과에서는 개인창작·전시·설치와 연결하고, 영상과 기술 결과에서는 영상촬영·내러티브·AI 이미지·영상·디지털 이미지와 연결한다. 어느 한쪽만 남겨 전문분야를 축소하지 않는다.

## 5. 교과·프로젝트 근거 사용 원칙

- 교과·프로젝트·진로·시설·교수진의 구조화 원본 레코드는 각 데이터 유형의 `active` 또는 `published` 상태이고 관리자 검증을 마친 경우에만 학생 결과의 근거로 사용한다. 초안, 보관, 비활성 또는 검증 전 레코드는 추천과 AI 입력에서 모두 제외한다.
- 교과명과 학년·학기는 `supabase/seed/curriculum-2026.json`에 있는 값만 사용한다.
- 교과가 `draft`이면 학생 결과에 노출하지 않는다. 관리자 검수와 게시를 거친 교과만 추천한다.
- 같은 교과가 여러 트랙 태그를 가지면 학생의 실제 관심 태그와 일치하는 이유만 설명한다.
- 교수의 학생 프로젝트와 진로는 `docs/content/faculty-directory-guide.md` 및 구조화 seed에 있는 문구를 우선한다.
- 특정 교과를 특정 교수가 담당한다고 확인되지 않았다면 담당 교과로 표현하지 않는다.
- 특정 프로젝트를 학년별 필수 과정이나 입학 후 보장된 참여로 표현하지 않는다.
- 확인된 근거가 없으면 비슷한 교과·프로젝트·직무명을 새로 만들어 채우지 않고 “확인된 학과 데이터를 준비 중입니다”를 사용한다.

## 6. 장비·시설은 실현 가능성을 보조하는 근거다

장비와 시설은 학생의 전공 방향을 결정하는 점수나 메인 콘텐츠가 아니다. “이 관심을 학과에서 어떤 환경으로 제작해 볼 수 있는가”를 뒷받침하는 `supporting evidence`로만 사용한다.

- 스튜디오 A(호리존): 인물·패션·제품·광고·영상 촬영 근거
- 스튜디오 B: 인물·제품·조명·사진영상 제작 실습 근거
- 암실: 흑백필름 현상과 인화 실습 근거
- 컴퓨터실: 사진 보정, 영상 편집·색보정, 디지털 이미지 제작 근거

학생 화면에서는 교과·프로젝트 연결 뒤에 가장 관련 높은 장비·시설 1–2개를 먼저 보여주고, 사용자가 펼칠 때 최대 4개까지 보여준다. 장비는 검증된 수량과 접근 방법만, 시설은 관리자가 확인한 운영 정보만 사용한다. 현재 `draft`이거나 확인이 필요한 시설은 검증·게시 전까지 학생 결과의 확정 근거로 노출하지 않는다.

금지 표현:

- “이 장비가 있으므로 이 전공에 적합합니다.”
- “입학하면 장비를 자유롭게 사용할 수 있습니다.”
- “이 시설에서 반드시 해당 프로젝트를 진행합니다.”

권장 표현:

- “선택한 관심을 실제 제작으로 이어갈 때 관련 교과와 함께 활용을 검토할 수 있는 학과 기반입니다.”
- “장비·시설의 이용 방법과 운영 여부는 학과 확인 후 안내합니다.”

## 7. 짧은 진로 제안 작성 기준

결과의 진로 제안은 학생의 방향성과 학과에서의 실현 가능성을 3–5문장으로 간결하게 설명한다.

1. 학생이 선택한 관심사와 상위 트랙을 한 문장으로 요약한다.
2. 게시된 교과와 프로젝트 중 실제로 연결된 근거를 한두 개 제시한다.
3. 총괄 상담교수와 필요한 전문 연계의 역할을 구분한다.
4. 확인된 진로 방향 또는 결과물 방향을 제안한다.
5. 장비·시설은 필요할 때 한 문장 이하의 보조 근거로만 언급한다.

AI 문장 생성을 사용하더라도 네 트랙 순위, 교과·프로젝트 추천, 교수진 추천은 기존의 결정적 규칙 결과를 그대로 사용한다. AI는 전달받은 검증 사실을 자연스러운 한국어로 정리할 뿐 새로운 교과, 장비, 교수 전문분야, 진로, 점수 또는 보장 표현을 만들지 않는다.

AI 제공자에게 보내는 입력은 결정적 규칙이 만든 최소 검증 사실 DTO로 제한한다. 학생의 전화번호, 닉네임, 학교명, 교수진의 원문 연락처와 `careerOther`를 포함한 모든 자유입력 원문은 보내지 않는다. 요청은 저장되지 않도록 `store: false`를 사용하고, 남용 방지를 위한 `safety_identifier`에는 원본 식별자가 아닌 가명화·해시된 값만 넣는다. AI 호출이 실패하거나 응답 검증을 통과하지 못하면 동일한 검증 사실로 만든 결정적 고정 템플릿 문장을 보여준다.

예시 구조:

```text
선택한 ‘{관심사}’는 {상위 트랙} 방향과 가장 가깝습니다.
학과에서는 ‘{게시 교과}’와 ‘{확인된 프로젝트}’를 통해 이 관심을 {결과물}로 발전시키는 경로를 살펴볼 수 있습니다.
{총괄 전임교원}이 전체 학습경로를 상담하고, 필요한 경우 {전문 연계 교원}의 실무 분야와 연결합니다.
이를 바탕으로 {확인된 진로 또는 결과물 방향}을 구체화해 볼 수 있습니다.
```

## 8. 결과 화면 용어

- 전임교원 1순위: `추천 총괄교수`
- 전임교원 2순위: `예비 상담교수`
- 겸임교원·실무전문가: `함께 연결되는 전문분야`
- 장비·시설 묶음: `이 제작을 가능하게 하는 학과 기반`

추천 단계에서는 `배정 완료`, `담당 교수`, `진로 확정`, `취업 보장`, `사용 보장`을 쓰지 않는다. 실제 상담교수 배정은 관리자 운영 화면에서 별도로 확정한다.

## 9. 관리자 검수 체크리스트

- [ ] 트랙 키가 `documentary`, `art_photo`, `commercial`, `video` 네 개뿐이다.
- [ ] 학생 표시명이 다큐멘터리 사진, 예술사진, 광고사진, 영상과 기술(AI·편집·드론)로 일치한다.
- [ ] AI·편집·드론·기술적 이미지를 별도 트랙으로 만들지 않았다.
- [ ] 관심사 키와 표시 문구가 게시된 평가 카탈로그와 일치한다.
- [ ] 교과명, 학년, 학기와 근거 태그가 2026 교과 seed와 일치한다.
- [ ] `draft` 또는 비공개 교과·프로젝트·시설을 학생 결과에 노출하지 않는다.
- [ ] 프로젝트와 진로 문구가 교수진 가이드 또는 승인된 구조화 데이터에 있다.
- [ ] 확인되지 않은 교수–교과 담당 관계를 만들지 않았다.
- [ ] 윤태준 교수의 예술사진·영상·AI·기술적 이미지 전문분야를 모두 반영했다.
- [ ] 사회·사람 기록과 지역·기관 아카이브에 따른 조대연·김사라 교수 역할 차이가 드러난다.
- [ ] 광고사진 결과가 특정 전임교원을 광고사진 전문가로 단정하지 않고 곽동욱 겸임교수를 전문 연계한다.
- [ ] 영상·드론·VR은 윤태준 교수 총괄과 박재웅 겸임교수 연계 원칙을 따른다.
- [ ] 전시기획·큐레이팅은 윤태준 교수 총괄과 정철호 겸임교수 연계 원칙을 따른다.
- [ ] 장비·시설이 트랙 결정이나 메인 결과가 아니라 교과·프로젝트의 보조 근거로 배치됐다.
- [ ] 장비 수량·접근 방법과 시설 운영 정보는 관리자 검증값만 사용한다.
- [ ] 추천과 실제 배정을 구분하고 보장 표현을 사용하지 않았다.
- [ ] AI 진로 제안이 결정적 추천 결과를 바꾸거나 검증되지 않은 사실을 추가하지 않는다.
- [ ] AI 입력이 최소 검증 사실 DTO이며 전화번호·닉네임·학교명·원문 연락처·자유입력 원문을 포함하지 않고, `store: false`, 해시된 `safety_identifier`, 결정적 실패 대체문을 사용한다.
