# 4개 분야 1~4학년 커리큘럼 루트 설계

## 목표

PHOTO:NEXT의 현재 파란색·둥근 카드·필름 타임라인 디자인을 유지한 채, 고등학생이 영상+AI·예술사진·다큐멘터리·광고사진의 1~4학년 학습 흐름을 한눈에 비교하고 결과 화면에서는 자신의 추천 경로를 자세히 확인할 수 있게 한다.

## 범위

- 메인 화면에는 4개 분야의 요약 경로를 선택 가능한 카드로 넣는다.
- 학생 결과 화면에는 1순위 분야를 기본으로 연 상세 경로를 넣고, 다른 세 분야도 전환해 비교할 수 있게 한다.
- 외부 페이지에서 그대로 사용할 수 있도록 CSS와 소량의 JavaScript가 모두 포함된 단일 HTML 파일을 제공한다.
- 기존 설문 점수, 교수 추천, 결과 데이터, 실제 수강신청 데이터는 변경하지 않는다.

## 정보 구조

### 공통 기반

네 경로 모두 1~2학년의 공통 기반을 먼저 보여준다. 실제 확인된 교과는 결과 데이터에서 계속 표시하며, 루트 안내에는 다음 제작 역량만 짧게 적는다.

| 학년 | 단계 | 안내 |
|---|---|---|
| 1학년 | 사진·영상 언어 기초 | 기초사진실기, 영상 에세이 메이킹, 영상 프레임과 컷처럼 카메라·프레이밍·촬영의 기초를 익힌다. |
| 2학년 | 제작·후반작업 확장 | 공통으로 사진커뮤니케이션, 다큐멘터리 메이킹&쇼케이스를 경험한다. 영상+AI 경로는 내러티브 영상촬영, 비주얼 스토리 메이킹, 영상 컬러와 포스트 프로덕션, 영상드론기초로 촬영·편집·색보정의 흐름을 확장한다. |

공통 구간은 특정 분야의 전용 과목이라고 표기하지 않는다.

### 분야별 심화 루트

| 분야 | 3학년 | 4학년 |
|---|---|---|
| 영상+AI | 영상 인터뷰 내러티브 워크숍, 영상 드론 콘텐츠 워크숍, 영상 콘텐츠 크리에이터 워크숍 | 예술사진 워크숍, 예술사진 랩 |
| 예술사진 | 사물,데이터,이미지 워크숍, 사진과 장소 그리고 콘텍스트 워크숍 | 예술창작 프로젝트 세미나, 예술창작 프로젝트 랩 |
| 다큐멘터리 | 포토 스토리 워크숍, 포토에세이 워크숍 | 다큐멘터리 세미나, 포스트 다큐멘터리 랩 |
| 광고사진 | 커머셜 포토그라피 기초 워크숍, 커머셜 포토그라피 심화 워크숍 | 커머셜 포토그라피 세미나, 커머셜 포토그라피 랩 |

영상+AI의 4학년 칸에는 확정 과목처럼 보이는 교과목 뱃지를 사용하지 않는다. 해당 학생의 2순위가 예술사진·다큐멘터리·광고사진이면, 기존 결과 추천 규칙이 그 분야의 확인된 4학년 과목을 별도로 연결하는 현재 동작을 유지한다.

## 화면 설계

### 공통 컴포넌트

새로운 CurriculumRouteExplorer는 네 분야 데이터를 받아 표시하는 읽기 전용 컴포넌트다.

- 상단: CURRICULUM / FOUR YEARS 라벨, 제목, 짧은 안내
- 분야 전환: 네 개의 파란 외곽선 pill 버튼. 활성 항목만 진한 파란 배경.
- 타임라인: 1Y, 2Y는 공통 기반 카드, 3Y, 4Y는 활성 분야 색 강조 카드.
- 카드: 학년, 단계, 과목/제작 단계, 결과물 한 줄을 담는다.
- 3·4학년의 확인된 과목에는 기존과 동일한 작고 절제된 전공필수/전공선택 뱃지를 적용할 수 있게 데이터 모델을 열어 둔다. 이번 루트 안내는 개설 안내이며 수강신청표가 아니다.
- 모바일에서는 가로 타임라인을 세로 4단계로 전환한다.

메인에서는 이 컴포넌트를 접힌 요약 높이로 사용한다. 결과 화면에서는 추천 1순위 트랙을 기본 선택값으로 주고, 전체 카드와 안내를 표시한다.

### 단일 HTML

public/curriculum-routes.html은 외부 의존성 없이 아래를 포함한다.

- 인라인 CSS: PHOTO:NEXT의 파란색, 옅은 회색 캔버스, 둥근 패널, 모노 라벨, 반응형 레이아웃
- 인라인 JavaScript: 네 분야 전환과 접근 가능한 aria-selected 처리만 제공
- 네 분야의 전체 루트를 담되, URL·학생 데이터·설문·관리자 기능은 포함하지 않는다.

배포 후 이 파일은 /curriculum-routes.html로 열리며, 사용자는 파일을 내려받아 다른 페이지에 사용할 수 있다.

## 데이터와 연결

- TrackKey와 표시 이름은 기존 shared/types/domain.ts의 키를 그대로 쓴다: video, art_photo, documentary, commercial.
- 새 정적 콘텐츠 모듈은 공통 기반과 네 분야 루트를 단일 source of truth로 가진다.
- ResultTimeline.vue는 snapshot.rankedTracks[0]를 이 컴포넌트의 기본 트랙으로 넘긴다.
- 메인 화면은 기본 선택을 video로 두되 사용자가 네 분야를 즉시 바꿀 수 있게 한다.
- 결과 화면의 기존 LearningPath는 실제 확인된 개설 교과를 계속 보여준다. 새 컴포넌트는 진로 탐색용 요약 루트여서 이를 대체하지 않는다.

## 오류 처리와 접근성

- 알 수 없는 트랙 키가 오면 영상+AI가 아니라 첫 번째 유효 루트를 표시하고, 콘솔 오류 없이 안전하게 렌더링한다.
- 탭 전환은 버튼이며 키보드 초점과 aria-pressed 상태를 제공한다.
- 색만으로 선택 상태를 전달하지 않는다. 활성 버튼에 선택됨 텍스트 또는 상태를 함께 표시한다.

## 검증

- 콘텐츠 단위 테스트: 네 트랙, 4개 학년, 3·4학년의 지정 과목, 영상+AI 4학년의 비-교과목 안내를 검증한다.
- 컴포넌트 테스트: 기본 트랙 렌더링, 전환, 알 수 없는 트랙 fallback을 검증한다.
- 정적 HTML 테스트: 네 탭과 각 분야의 핵심 과목, 외부 JS/CSS 참조가 없음을 검증한다.
- 기존 결과 타임라인 테스트를 확장해 결과 페이지에 추천 트랙이 전달되는지 검증한다.

## 제외

- 새로운 DB 테이블·마이그레이션·관리자 편집 화면
- 과목별 학점·학기·강의계획서의 임의 생성
- 수강신청 가능 여부 안내
- 네 분야 외 추가 전공 트랙
