# 관리자 기능 정리와 오류 안내 설계

## 목표

관리자 화면에서 사용하지 않는 `AI 문장 신고`와 `캠페인 운영` 기능을 제거하고, 상담 운영 및 XLSX 내보내기가 실패했을 때 운영자가 원인과 다음 행동을 바로 알 수 있게 한다.

## 범위

### 제거하는 기능

- 관리자 메뉴의 `AI 문장 신고`, `캠페인 운영`
- 두 관리자 페이지와 전용 API
- 학생 결과 화면의 AI 문장 신고 제출 UI와 전용 API
- 캠페인 링크 생성·조회·보관 UI와 전용 API
- 상담 및 내보내기의 캠페인 필터
- 더 이상 호출되지 않는 전용 스키마, 서비스, 컴포넌트 및 테스트
- 캠페인 쿠키 생성과 신규 유입 귀속 처리

### 보존하는 데이터

- 기존 설문·상담·이벤트에 저장된 과거 캠페인 식별자
- 기존 캠페인 및 AI 문장 신고 테이블의 과거 행
- 기존 데이터베이스 외래키와 감사 기록

보존 데이터는 새 화면이나 공개 API에서 읽고 쓰지 않는다. 물리 삭제는 기존 참여 이력을 손상할 수 있으므로 이번 변경에 포함하지 않는다.

## 오류 안내

상담 운영과 데이터 내보내기는 서버 응답의 안전한 오류 코드와 현재 처리 단계를 해석한다. 원본 데이터베이스 오류, 토큰, 내부 경로는 화면에 노출하지 않는다.

| 분류 | 사용자에게 표시할 원인 | 다음 행동 |
| --- | --- | --- |
| 인증·권한 | 관리자 로그인 세션이 만료되었거나 권한을 확인할 수 없음 | 로그인 화면으로 이동 |
| 잘못된 필터 | 입력한 조회·내보내기 범위가 올바르지 않음 | 표시된 필터 수정 |
| 행 수 초과 | 결과가 XLSX 허용 범위를 초과함 | 대상·교수·날짜 필터로 축소 |
| 변경 충돌 | 작업 도중 서버 상태가 변경됨 | 새 작업으로 다시 시작 |
| 네트워크 | 요청이 서버까지 도달하지 못했거나 응답이 끊김 | 연결 확인 후 재시도 |
| 응답 형식 | 서버 응답을 안전하게 확인할 수 없음 | 새로고침 후 재시도 |
| 워크북 생성 | 브라우저에서 XLSX 파일 생성에 실패함 | 재시도 또는 다른 브라우저 사용 |
| 다운로드 | 파일은 생성됐으나 브라우저 다운로드가 시작되지 않음 | 다운로드 권한 확인 후 재시도 |
| 서버 처리 | 서버 또는 데이터베이스 처리 중 실패함 | 재시도하고, 반복 시 요청 번호 전달 |

알 수 없는 서버 오류에는 응답에 포함된 `requestId`만 운영용 요청 번호로 표시한다. 상세 예외 메시지는 표시하지 않는다.

## 화면 구성

- 기존 파란색·라운드 관리자 디자인을 유지한다.
- 오류 영역은 `실패한 작업`, `이유`, `해결 방법`, `요청 번호` 순서로 짧게 표시한다.
- 빈 목록과 실패 상태를 구분한다. 데이터가 0건이면 오류가 아니라 빈 상태로 표시한다.
- 재시도가 가능한 오류에만 `다시 시도`를 표시하고, 인증 오류는 `다시 로그인`을 표시한다.

## 데이터 흐름

1. 서버 API는 기존처럼 정규화된 오류 코드와 요청 번호만 반환한다.
2. 공통 클라이언트 오류 해석기가 오류 코드·HTTP 상태·현재 단계에 따라 안전한 안내 문구를 만든다.
3. 상담 운영과 XLSX 내보내기가 같은 규칙으로 오류를 표시한다.
4. 삭제 대상 페이지와 API는 빌드 결과에 포함되지 않으며 해당 URL은 404가 된다.

## 카메라·렌즈 추천 우선순위

기자재는 진로 추천의 주인공이 아니라 학습경로를 수행할 수 있음을 뒷받침하는 근거로 유지한다. 시설 2개, 카메라 바디 1개, 렌즈 1개를 먼저 구성하는 기존 결과 구조는 바꾸지 않는다.

- 사진·광고사진 관심에는 Sony·Canon 카메라 바디와 호환 렌즈를 우선한다.
- 영상·기술 관심에는 Sony FX3, A7SII, PXW FS7 등 영상 제작에 적합한 Sony 바디를 우선한다.
- 필름·암실 관심에는 Canon EOS 필름 바디와 호환 렌즈를 우선한다.
- 다른 브랜드는 학생 관심과의 적합도가 Sony·Canon 후보보다 명확히 높거나 Sony·Canon 후보가 검증되지 않았을 때 사용할 수 있다.
- 브랜드 선호는 관심 적합도와 검증 상태 다음의 제한된 우선순위로 적용해 결과를 왜곡하지 않는다.
- 바디와 렌즈는 가능한 경우 같은 마운트 계열로 묶되, 현재 데이터로 호환성을 확인할 수 없으면 브랜드명만으로 호환을 단정하지 않는다.

## 검증 기준

- 관리자 메뉴에 두 삭제 기능이 나타나지 않는다.
- 삭제된 관리자·학생 API와 페이지 URL은 사용할 수 없다.
- 상담 실패 테스트에서 인증, 필터, 네트워크, 서버 오류가 서로 다른 이유로 표시된다.
- 내보내기 실패 테스트에서 행 수, 인증, 수집, 워크북, 다운로드 실패가 서로 구분된다.
- 상담·내보내기 화면에서 캠페인 필터가 사라진다.
- 사진·광고사진 결과에서는 Sony 또는 Canon 바디·렌즈가 우선 노출된다.
- 영상·기술 결과에서는 Sony 영상 바디가 우선 노출된다.
- 필름·암실 결과에서는 Canon EOS 계열이 우선 노출된다.
- 기존 학생 설문, 결과, 상담, 교수진, 명단 기능은 회귀 없이 동작한다.
- 린트, 타입 검사, 단위·통합·E2E 테스트, 프로덕션 빌드가 통과한다.
