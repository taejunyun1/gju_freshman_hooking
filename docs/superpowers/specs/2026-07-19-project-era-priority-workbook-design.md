# PHOTO:NEXT 프로젝트 연도 우선순위 통합 엑셀 설계

## 목적

사용자가 작성한 프로젝트 입력 엑셀과 2026년 K-컬처리딩센터 세부 프로그램 표를 하나의 검토 가능한 통합본으로 정리한다. 이 통합본은 이후 데이터베이스 반영과 결과 화면 노출 정책의 원본으로 사용한다.

이번 단계에서는 엑셀 통합본만 제작한다. 데이터베이스와 프론트엔드 변경은 통합본 검토가 끝난 뒤 별도 구현 계획으로 진행한다.

## 입력 자료

1. `photo-next-project-intake-template_PHOTO-NEXT_2024이전경험_반영.xlsx`
   - 2025년 완료 RISE 사례 16건
   - 2024년 및 이전 경험 14건
2. `K-컬처리딩센터 3+1 전략 기반 학과별 세부프로그램 수요조사서` 화면 캡처
   - 2026년 학과 배정 및 센터 지원 프로그램

## 통합 원칙

### 연도별 노출 단계

- 2026년 프로그램: `현재_우선`
- 2025년 완료 사례: `최근_사례`
- 2024년 및 이전 자료: `축적_경험`

`현재_우선`은 결과 화면의 메인 프로젝트 후보가 된다. `최근_사례`와 `축적_경험`은 이후 결과 화면에서 합계 3건의 짧은 경험 카드 후보로 사용한다.

### 2026년 자료 정규화

- 같은 활동이 학과 배정 예산과 센터 지원 예산에 반복 기재된 경우 하나의 프로그램으로 합친다.
- 동일한 프로그램의 교육과 쇼케이스가 하나의 흐름일 때 한 행으로 합친다.
- 서로 다른 장소, 담당교수 또는 학습 목적을 가진 기관탐방은 개별 행으로 유지한다.
- `사진단오제(남구청)`는 취소가 명시되어 있으므로 통합 엑셀과 서비스 데이터에서 완전히 제외한다.
- 완료 근거가 없는 2026년 항목은 완료로 표시하지 않고 `예정` 또는 `검토중`으로 기록한다.
- 예산은 추천과 화면 노출에 필요하지 않으므로 핵심 입력 열로 추가하지 않는다. 원본 표와의 대조가 필요한 사항만 검증메모에 남긴다.

2. K-컬처 기관탐방 — 부산 금정문화회관·금샘미술관

7. 광주 3·10 독립만세운동 재현행사 촬영

13. K-컬처 오픈랩 연계 사진전시 2회

## 워크북 구조

### `프로젝트_통합`

기존 입력 템플릿의 A~U 열을 그대로 유지한다. 따라서 기존 검증 규칙과 향후 변환 스크립트가 깨지지 않는다.

뒤쪽에 다음 열만 추가한다.

- V `사업연도`
- W `노출단계`
- X `사업그룹`
- Y `운영학기`
- Z `표시분류`

`표시분류` 값은 `메인프로젝트`, `최근사례`, `짧은경험` 중 하나로 제한한다.

### `노출_요약`

연도별·노출단계별 건수를 수식으로 집계한다. 화면 반영 규칙도 짧게 표시한다.

- 2026 현재 우선: 관심사 기준 최대 3건
- 2025 최근 사례와 2024년 이전 축적 경험: 합계 3건
- 축적 경험 카드는 연도, 프로젝트명, 핵심 역량 한 문장만 표시

### 기존 편집 지원 시트

`작성_가이드`와 `태그_목록`은 유지한다. 새 분류 열의 허용값과 작성 예시는 가이드에 추가한다.

## 품질 기준

- 기존 30개 입력 행의 핵심 값과 서식을 보존한다.
- 2026년 정규화 행 13개가 누락 없이 존재한다.
- 프로젝트 키는 모두 고유하다.
- 대표트랙, 관심태그, 관련교수와 연계문구가 빈칸 없이 작성된다.
- 2026년 완료 여부를 추정하지 않는다.
- 취소 항목은 통합 엑셀, 요약 집계, 데이터베이스, 결과 화면에 포함하지 않는다.
- 수식 오류가 없고 필터, 고정 행, 데이터 검증이 정상 동작한다.
- 렌더링한 시트에서 제목, 헤더, 긴 설명과 분류 값이 잘리지 않는다.
