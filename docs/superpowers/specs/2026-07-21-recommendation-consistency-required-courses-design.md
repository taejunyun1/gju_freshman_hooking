# 추천 정합성 보정 및 전공필수 교과 표시 설계

## 목적

PHOTO:NEXT의 기존 결정형 추천 구조를 유지하면서 다음 일곱 가지를 순서대로 보정한다.

1. 강사·겸임 추천의 후보 근거, 순위 근거, 화면 설명 근거를 하나로 통일한다.
2. 전임교원의 전문분야를 유지하면서 혼합·경계 응답의 총괄 추천을 세 교수에게 더 고르게 분산한다.
3. 영상과 기술이 1순위인 학생의 진로 문장에 2순위 분야와 그 분야의 4학년 교과를 반영한다.
4. 다큐멘터리 선택지가 구조적으로 낮게 추천되는 편향을 완화한다.
5. 광고사진 경로의 전임교원 설명을 총괄상담과 실무연계 구조에 맞게 보정한다.
6. 관심 점수, 교육환경 점수, AI 비사용 상태를 화면에서 정확히 설명한다.
7. 공식 2026 교과자료에서 확인된 전공필수 교과를 모든 새 추천 결과에 포함하고 작은 배지로 표시한다.

OpenAI API는 사용하지 않는다. 신규 외부 서비스, 신규 네트워크 호출, 별도 추천 엔진은 추가하지 않는다.

## 검토한 접근

### A. 기존 파이프라인의 근거 계약만 보강 — 채택

현재 점수·교과·교수진·결과 스냅샷 구조를 유지하고, 각 단계에서 사용되는 근거를 명시적으로 연결한다. 데이터 필드와 결정형 문장만 필요한 만큼 확장한다. 배포 비용과 운영 복잡도가 증가하지 않고 기존 테스트 자산을 그대로 활용할 수 있다.

### B. 추천 규칙을 별도 규칙 엔진과 테이블로 분리 — 제외

관리 유연성은 높지만 약 200명 규모의 연 1회 운영에는 과도하다. 신규 테이블, 관리자 UI, 캐시 무효화와 배포 위험이 늘어난다.

### C. seed 문구와 가중치만 수정 — 제외

빠르지만 강사 추천에서 후보 근거와 표시 이유가 달라지는 런타임 문제, 영상 2순위 진로 문장 문제, 전공필수 누락을 해결하지 못한다.

## 1. 강사·겸임 추천 근거 통일

전문 연계 후보를 단순한 교수 ID 집합으로 축약하지 않고 `전문가 + 연결 링크 + 일치 태그 + 선택 근거 + 점수`의 단일 매치 기록으로 유지한다.

- 선택된 총괄교수와 연결된 링크 또는 `primaryFacultyId = null`인 학과 공통 링크만 후보가 된다.
- 링크의 `tagKey`에 실제 학생 신호가 있고, 해당 강사의 검증된 전문 태그에도 같은 키가 있을 때만 유효하다.
- 후보 자격, 순위의 주 점수와 화면 추천 이유는 모두 이 동일한 링크 태그를 사용한다.
- 링크별 `priority`를 실제 동점 정렬에 반영한다.
- 강사의 다른 결과·진로 태그는 동점 보조 근거로만 사용하며 화면 이유를 바꾸지 않는다.
- 최대 2명, 전임교원보다 작은 카드, 지원 역할이라는 현재 UI 구조는 유지한다.

세부 관심을 우선한다. 예를 들어 `exhibition` 또는 `curating` 신호가 있으면 넓은 `art_photo` 연결보다 정철호 겸임교수의 구체 링크가 우선하며, `drone`·`vr`·`360`은 박재웅 겸임교수, 광고·패션·제품은 곽동욱 겸임교수의 구체 링크를 우선한다.

## 2. 전임교원 추천 분산

윤태준 교수의 예술사진·영상·AI 전문성, 조대연 교수의 사회·사람·포토커뮤니케이션 전문성, 김사라 교수의 지역·기관·아카이브 전문성을 변경하지 않는다. 대신 한 교수의 전문분야가 명백한 강한 신호와 혼합·경계 신호를 구분한다.

- 강한 단독 전문 신호가 있고 1·2순위 점수 차이가 50점 이상이면 기존 전문분야 소유 교수를 우선한다.
- 그 외 혼합·경계 응답에서는 실제 일치 전문 태그가 있는 전임교원을 안정적인 학생 분배키로 순환한다.
- 전문 근거가 0인 교수는 단순 균등화를 위해 후보 풀에 넣지 않는다.
- 동일 학생·동일 응답은 언제나 같은 결과를 받는다.
- 운영 선택 조합 전수검사에서 윤태준 교수는 55% 이하, 조대연·김사라 교수를 포함한 세 전임교원은 각각 20% 이상이 되도록 회귀 기준을 둔다.
- 목표는 기계적인 1:1:1이 아니라 전문성 범위 안의 완만한 분산이다.

## 3. 영상 1순위 + 2순위 진로 문장

영상과 기술이 1순위이고 2순위가 예술사진·다큐멘터리·광고사진 중 하나이면 결정형 진로 문장을 연결형으로 만든다.

- 첫 문장은 기존 `direction_bridge_v1`을 사용해 영상과 기술을 중심으로 2순위 분야까지 탐색한다고 설명한다.
- 첫 관심사는 카탈로그 저장 순서가 아니라 1순위 트랙 점수에 가장 크게 기여한 실제 선택지를 사용한다.
- 학습 문장은 영상 3학년 경로 교과 한 과목과 2순위 분야의 검증된 4학년 교과 한 과목을 우선 사용한다.
- 확인된 4학년 교과가 없으면 기존 안전한 기초 문장으로 되돌아간다.
- 영상이 1순위가 아닌 결과는 기존 단일 방향 문장을 유지한다.

문장 근거 ID는 실제 결과 스냅샷 안의 관심사·트랙·교과만 참조하고, 화면 타임라인과 다른 과목을 말하지 않는다.

## 4. 다큐멘터리 선택지 균형

새 문항을 추가하지 않고 의미상 다큐멘터리 성격이 강한 작업 선택지 두 개의 가중치만 보정한다.

| 선택지 | 현재 | 변경 |
|---|---|---|
| 인물·풍경·일상을 사진으로 촬영하기 | 다큐 2, 예술 3 | 다큐 3, 예술 2 |
| 브랜드·지역을 위한 콘텐츠 만들기 | 다큐 2, 광고 3 | 다큐 3, 광고 2 |

두 문항 모두 사람·일상·지역 기록이라는 다큐멘터리 성격이 명확하다. 다른 문항, 그룹 가중치 `work 40 / result 30 / style 10 / career 20`, 동점 규칙은 변경하지 않는다.

운영 최소 선택 조합 1,920개 전수검사에서 각 트랙의 1순위 비율이 15% 이상 40% 이하인지 회귀 테스트로 고정한다. 예상 분포는 다큐멘터리 약 16.3%, 예술사진 약 25.5%, 광고사진 약 24.9%, 영상과 기술 약 33.3%다.

## 5. 광고사진 총괄 설명

광고사진은 특정 전임교원을 광고 전문가로 표현하지 않는다. 광고사진이 단독 또는 공동 1순위인데 전임교원 소유 전문 트랙이 없는 경우 다음 역할 구조를 사용한다.

- 전임교원: 전체 학습경로와 상담을 총괄한다.
- 곽동욱 겸임교수: 광고·패션·제품·뷰티·브랜드 이미지 실무를 연계한다.
- 실제 상담 담당자는 학과가 최종 배정한다.

총괄교수의 개인 전문분야와 광고사진이 직접 일치한다는 문장은 만들지 않는다. 다른 트랙의 총괄·예비 설명은 유지한다.

## 6. 화면 용어

- `관심 분야 연결 점수`를 `응답 기반 관심 방향`으로 바꾼다.
- 설명은 네 점수가 설문 선택과 네 관심 분야의 가까움을 나타낸다고 명시한다.
- `교육환경 연결도`를 `교육환경 근거 충족도`로 바꾼다.
- 설명은 검증된 시설·장비·교과·교수진 근거의 충족 여부임을 명시한다.
- OpenAI 비활성 운영에서 `AI가 도움을 줄 수 있다`는 안내를 제거한다.
- 대신 `선택한 응답과 확인된 학과 데이터로 구성한 안내`라고 표시한다.

새 강조색을 추가하지 않고 기존 파란색·남색·흰색 토큰만 사용한다.

## 7. 전공필수 교과

### 공식 기준

`curri-data.pdf`의 2026학년도 개설 예정 표에서 다음 다섯 과목이 `전필`로 확인된다.

1. 1학년 2학기 `라이팅과 스튜디오`
2. 2학년 1학기 `디지털 이미지 제작과 프린트`
3. 2학년 2학기 `영상 컬러와 포스트 프로덕션`
4. 3학년 1학기 `커머셜 포토그라피 기초 워크숍`
5. 3학년 2학기 `커머셜 포토그라피 심화 워크숍`

### 데이터 계약

- 교과 metadata에 `requirement_type: major_required | major_elective`를 추가한다.
- seed JSON과 생성 SQL에 41개 교과의 공식 이수구분을 기록한다.
- 운영 DB의 2026 교과 metadata를 같은 값으로 갱신하는 migration을 추가한다.
- 관리자 교과 편집 화면에는 `전공필수 / 전공선택` 선택 필드를 추가한다.
- 새로 공개하는 교과는 이수구분이 없으면 게시할 수 없게 한다.
- 결과 스냅샷에는 `displayMetadata.requirementType`을 전달한다. 과거 스냅샷 호환을 위해 이 필드는 선택값으로 읽되, 새 결과에는 항상 포함한다.

### 추천 포함 규칙

- 활성·학생 공개·2026 교과 중 `major_required` 다섯 과목을 모든 새 결과에 반드시 포함한다.
- 관심사 점수가 0이어도 전공필수라는 학과 공통 근거로 포함한다.
- 이미 맞춤 경로나 일반 추천으로 선택된 동일 교과는 ID 기준으로 한 번만 표시한다.
- 기존 3·4학년 맞춤 경로와 영상 2순위 4학년 경로는 제거하지 않는다.
- 최대 구성은 일반 기초 교과 5개 + 전공필수 5개 + 맞춤 경로 5개, 총 15개다.
- 학년별 최대 5개 제한은 유지한다. 실제 공식 편성에서는 3학년 영상 경로 3개와 전공필수 2개가 최대다.
- 전공필수 연결 설명은 관심 적합도를 과장하지 않고 `학과의 공통 제작 기반을 익히는 전공필수 교과`라고 표시한다.

### 배지 디자인

교과 카드 상단의 `COURSE` 바로 옆에 `전공필수` 배지를 표시한다.

- 기존 primary blue의 8~10% 배경과 30% 테두리
- 남색 글자, 10px 안팎의 mono/utility 글꼴
- 완전한 pill보다 기존 카드 곡률에 맞춘 작은 라운드 사각형
- 새 색상, 아이콘, 굵은 그림자 사용 금지
- 전공선택 카드는 배지를 표시하지 않는다.
- 스크린리더가 과목명과 함께 `전공필수`를 읽을 수 있게 텍스트로 구현한다.

## 호환성과 데이터 흐름

1. 설문 완료 시 기존 점수 계산과 추천 교수 선정을 수행한다.
2. 보정된 선택지 가중치로 네 트랙 순위를 만든다.
3. 강한 전문 신호는 보존하고 혼합·경계 신호는 전문 근거가 있는 전임교원 사이에서 안정적으로 분산한다.
4. 같은 근거 매치로 지원 강사를 구성한다.
5. 기존 맞춤 교과에 전공필수 다섯 과목을 중복 없이 병합한다.
6. 영상 1순위이면 2순위 4학년 교과를 유지하고 결정형 진로 문장에도 반영한다.
7. 결과 스냅샷을 검증한 후 저장한다.

기존 저장 결과는 재작성하지 않는다. 변경 후 새로 완료하거나 `결과 다시 만들기`를 실행한 결과부터 새 추천이 적용된다.

## 테스트와 검증

각 작업은 테스트를 먼저 실패시킨 뒤 최소 구현으로 통과시킨다.

- 강사 후보 링크, 순위, 표시 이유가 동일 태그를 사용하는 단위 테스트
- 세 전임교원 추천 분포가 `각 20% 이상`, 윤태준 교수 `55% 이하`인지 확인하는 1,920개 조합 회귀 테스트
- 전시·큐레이팅, 드론, 광고, 다큐·영상 혼합 사례의 강사 최대 2명 회귀 테스트
- 영상 1순위 세 가지 2순위 조합의 연결 문장과 4학년 교과 근거 테스트
- 1,920개 선택 조합의 트랙 분포 범위 테스트
- 광고사진 총괄 전용 문구와 곽동욱 실무연계 테스트
- 공식 전공필수 정확히 5개, 모든 새 결과 포함, 중복 제거, 총 15개 상한 테스트
- 전공필수 배지 렌더링·전공선택 미표시 컴포넌트 테스트
- 과거 스냅샷 호환 테스트
- 전체 단위·통합 테스트, 타입 검사, 프로덕션 빌드
- 배포 후 신규 더미 결과에서 모바일·데스크톱 교과 카드와 추천 문장 smoke 확인

## 제외 범위

- 확인되지 않은 2026 광고사진 프로젝트를 새로 만들지 않는다.
- 교수 전문분야를 무시한 단순 1:1:1 균등 배분을 하지 않는다.
- 기존 카메라·렌즈·시설 추천 규칙은 이번 작업에서 변경하지 않는다.
- OpenAI API를 다시 활성화하지 않는다.
- 과거 학생 결과를 일괄 재작성하지 않는다.
