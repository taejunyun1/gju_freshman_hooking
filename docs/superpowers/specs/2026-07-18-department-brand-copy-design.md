# 광주대학교 사진영상미디어학과 브랜드 문구 통일 설계

## 목표

PHOTO:NEXT의 모든 핵심 사용자 접점에서 운영 주체가 **광주대학교 사진영상미디어학과**임을 분명하게 전달한다. `PHOTO:NEXT`는 독립 기관처럼 보이는 주 브랜드가 아니라, 학과가 지원자의 관심사를 교과·프로젝트·교수진·진로와 연결해 보여주는 서비스 이름으로 유지한다.

학생은 어느 화면에서 처음 진입하더라도 다음 내용을 이해할 수 있어야 한다.

1. 이 서비스는 광주대학교 사진영상미디어학과가 제공한다.
2. 자신의 사진·영상 관심사가 학과의 실제 학습 경로와 어떻게 이어지는지 확인할 수 있다.
3. 기자재와 시설은 진로를 결정하는 메인 콘텐츠가 아니라, 해당 작업을 학과에서 실현할 수 있음을 보여주는 지원 근거다.

## 브랜드 관계

- 주체: `광주대학교 사진영상미디어학과`
- 서비스명: `PHOTO:NEXT`
- 공통 결합 표기: `광주대학교 사진영상미디어학과 · PHOTO:NEXT`
- 문서 제목·검색 결과 표기: `광주대학교 사진영상미디어학과 | PHOTO:NEXT`
- 접근성 홈 링크: `광주대학교 사진영상미디어학과 PHOTO:NEXT 홈`

화면의 첫 브랜드 노출이나 핵심 설명에서는 정식 학과명을 사용한다. 같은 화면 안에서 반복되는 후속 문장과 기능 라벨은 `학과`로 줄여 읽기 부담을 낮춘다. `우리 학과`처럼 화자의 소속을 전제하는 표현은 사용하지 않는다.

## 핵심 메시지

### 랜딩

- 브랜드 라벨: `광주대학교 사진영상미디어학과 · PHOTO:NEXT`
- 핵심 제목: `하고 싶은 사진·영상, 광주대학교 사진영상미디어학과에서 어떻게 시작할 수 있는지 확인해보세요.`
- 설명: 학생이 선택한 관심사가 학과의 `교과과정 → 프로젝트·비교과 → 교수진 → 진로`로 이어지는 경로를 보여준다고 명시한다.
- 시작 행동은 진단이나 검사 같은 평가 어휘보다 `내 관심사 연결 경로 시작하기`처럼 탐색 행동을 사용한다.

### 학생 로그인과 관심사 선택

- 로그인 첫 설명에서 광주대학교 사진영상미디어학과 지원자용 서비스임을 밝힌다.
- 관심사 선택 화면의 첫 안내는 `광주대학교 사진영상미디어학과에서 탐색할 관심`이라는 맥락을 제공한다.
- 단계별 질문과 선택지는 현재의 쉬운 학생 언어를 유지하며 전체 학과명을 반복하지 않는다.

### 결과·이력·상담

- 결과 첫 문단에서 선택한 관심이 광주대학교 사진영상미디어학과의 4년 학습 경로로 어떻게 이어지는지 설명한다.
- 결과 내부의 교과, 교수진, 진로, 프로젝트 섹션은 이후 `학과`라는 축약 표현을 사용한다.
- 이력은 `광주대학교 사진영상미디어학과와 연결해 본 관심사`라는 목적을 첫 설명에 표시한다.
- 상담은 추천 교수의 자동 배정이 아니라 학과가 최종 상담 담당자를 확인한다는 기존 운영 원칙을 유지한다.
- 장비·시설은 현재 정보 계층을 유지하고 `이 제작을 가능하게 하는 학과 기반`으로만 표시한다.

### 관리자

- 관리자 로그인과 공통 셸에는 `광주대학교 사진영상미디어학과 운영`을 표시한다.
- 학생, 명단, 상담, 자원, 교수진 같은 내부 메뉴와 작업 버튼은 현재의 짧은 기능명을 유지한다.
- 관리자 오류·빈 상태에서 정식 학과명을 불필요하게 반복하지 않는다.

## 공통 문구 경계

정식 명칭과 결합 표기는 공통 브랜드 상수에서 관리한다. 화면마다 직접 문자열을 새로 만들지 않는다. 페이지 제목, 메타 설명, 홈 링크의 접근성 이름도 같은 상수를 사용한다.

공통 상수는 최소한 다음 값을 제공한다.

- 정식 학과명
- 서비스명
- 결합 브랜드명
- 문서 제목용 브랜드명
- 홈 링크 접근성 이름

화면별 설명 문장은 각 페이지가 담당한다. 모든 문장을 하나의 거대한 카피 사전에 모으지 않아 수정 범위와 의존성을 작게 유지한다.

## 상태·오류·빈 화면

- 공개 데이터가 없을 때는 `광주대학교 사진영상미디어학과에서 확인한 자료를 준비 중입니다`처럼 데이터의 확인 주체를 첫 빈 상태에서 분명히 한다.
- 같은 페이지에서 반복되는 후속 빈 상태는 `확인된 학과 데이터를 준비 중입니다`를 유지할 수 있다.
- 오류 문구는 브랜드 홍보가 아니라 사용자의 다음 행동을 안내해야 한다. 네트워크·세션·입력 오류에 전체 학과명을 기계적으로 삽입하지 않는다.
- 사실 확인이 필요한 교과·장비·운영 정보는 기존처럼 확정 표현을 피하고 학과 확인 후 안내한다.

## 보존 대상

다음 값은 현재 브랜드 카피가 아니라 사실·출처 기록이므로 일괄 치환하지 않는다.

- 졸업 당시의 학과명과 학력 표기
- 교수진 소개에 포함된 과거 소속·학과명
- 문서 원문 제목과 `sourcePageTitle`
- 외부 기관이 사용한 공식 프로젝트명
- 데이터 마이그레이션과 테스트 픽스처가 과거 상태를 재현하기 위해 사용하는 문자열

현재 학과를 지칭하는 소개·운영 문구의 `사진영상학과`는 `사진영상미디어학과`로 바로잡되, 위 보존 대상과 구분해서 수정한다.

## 디자인 유지 범위

블루 포토 노트의 색상, 라운드 형태, 정보 계층, 제목 크기 상한은 변경하지 않는다. 이번 작업은 브랜드 잠금 표기와 문장 계층을 정돈하는 카피 변경이다. 긴 정식 명칭이 320px 화면에서 자연스럽게 줄바꿈되도록 기존 헤더와 제목 영역의 오버플로우만 함께 확인한다.

## 검증

### 자동 검증

- 공통 브랜드 상수의 정식 명칭과 결합 표기를 검증한다.
- 랜딩, 로그인, 관심사 선택, 결과, 이력, 상담, 관리자 로그인·셸의 첫 노출에 정식 학과명이 포함되는지 검증한다.
- 사용자 화면의 현재 학과 소개에 구 명칭 `광주대학교 사진영상학과`가 남지 않는지 검증한다.
- 과거 학력·졸업 학과명과 출처 원문은 변경되지 않았는지 검증한다.
- 기존 기능 테스트, 타입 검사, 린트, 프로덕션 빌드를 통과한다.

### 브라우저 검증

- 랜딩, 학생 로그인, 관심사 선택, 결과, 관리자 로그인과 관리자 홈을 1280px와 320px에서 확인한다.
- 정식 학과명 줄바꿈으로 가로 오버플로우가 생기지 않는지 확인한다.
- 페이지 제목의 시각 크기가 기존 32px 상한을 유지하는지 확인한다.
- 홈 링크의 접근성 이름이 정식 학과명과 PHOTO:NEXT를 함께 전달하는지 확인한다.

## 비목표

- 서비스명 `PHOTO:NEXT`를 삭제하거나 학과명으로 대체하지 않는다.
- 기능, API, 데이터베이스 스키마, 인증 흐름을 변경하지 않는다.
- 기자재·시설을 결과의 메인 콘텐츠로 올리지 않는다.
- 과거 학과명과 출처 원문을 현재 명칭으로 소급 수정하지 않는다.
- 모든 문장에 정식 학과명을 반복하지 않는다.
