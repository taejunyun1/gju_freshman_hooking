# PHOTO:NEXT 관리자 비밀번호 전용 로그인 설계

## 목표

관리자 로그인을 Supabase 이메일/비밀번호 한 단계로 단순화한다. TOTP 등록, QR 코드, 6자리 인증 코드, MFA 전용 오류 흐름은 사용자 화면과 인증 필수 조건에서 제거한다.

## 승인된 동작

- 공개 관리자 회원가입은 만들지 않는다.
- 이메일/비밀번호가 맞더라도 `admin_users`의 활성 관리자만 접근할 수 있다.
- 비밀번호 로그인으로 발급된 Supabase `aal1` 토큰을 관리자 세션으로 인정한다. 기존의 더 강한 `aal2` 토큰도 호환을 위해 거부하지 않는다.
- 일반 관리자 세션의 절대 최대 수명은 기존과 같은 8시간이다.
- 전화번호 열람, 내보내기, 계정 복구처럼 `recentAuthMinutes: 15`를 사용하는 작업은 마지막 비밀번호 인증 후 15분 이내라는 기존 제한을 유지한다.
- 브라우저에는 refresh token을 저장하지 않고 기존처럼 메모리와 sessionStorage의 단기 access token만 사용한다.
- Supabase 로컬 TOTP 등록·검증을 끈다. 원격에 이미 등록된 factor를 삭제하거나 관리자 비밀번호를 바꾸지는 않는다.

## 화면 방향

대상은 학과 운영자이며 페이지의 한 가지 일은 관리자 자격 증명으로 운영 화면에 들어가는 것이다. 현재 PHOTO:NEXT 운영 패널의 차가운 캔버스, 보라색 식별색, 타이포그래피와 구조는 유지한다. `AAL2`, 인증 앱, QR, 6자리 코드처럼 사용자가 더 이상 제어하지 않는 용어와 두 번째 폼을 삭제하고, 제목·설명·버튼·오류를 이메일/비밀번호 로그인 동작에 맞춘다.

## 보안 경계

- 클라이언트 성공만 믿지 않고 `/api/admin/session`에서 JWT claims, 인증 시각, 활성 `admin_users` 행을 다시 검증한다.
- `aal`은 `aal1` 또는 `aal2`만 허용하고 알 수 없는 값은 인증 실패로 처리한다.
- 최근 인증 제한과 8시간 절대 제한은 서버에서 계산한다.
- 관리자 세션 만료나 재인증 오류가 발생하면 기존 고정 로컬 로그인 경로로 돌려보낸다.

## 범위 밖

- 관리자 계정 생성·비밀번호 변경
- OpenAI provider 설정
