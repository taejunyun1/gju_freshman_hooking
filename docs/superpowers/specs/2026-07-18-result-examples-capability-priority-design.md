# 결과 예시 콘텐츠·학과 기반 우선순위 설계

## 목적

결과 화면이 검증 콘텐츠 부족 때문에 빈 화면처럼 보이지 않도록, 학생의 선택과 4개 진로 카테고리에서 파생한 예시를 제공한다. 예시는 실제 확정 작품·프로젝트와 명확히 구분한다. 학과 기반은 공간을 먼저 보여주고 카메라·렌즈를 뒤에 배치해, 추천의 중심이 아니라 학습경로를 실현할 수 있는 근거로 유지한다.

OpenAI API는 사용하지 않는다. 모든 예시는 로컬 고정 카탈로그와 결정적 매칭으로 생성하며 외부 요청과 추가 비용이 없다.

## 콘텐츠 원칙

- 결과 예시는 `관심사 기반 예시`라고 표시한다.
- 검증된 교수·졸업생·시설·기자재 레코드와 예시를 같은 사실처럼 섞지 않는다.
- 예시는 학생이 선택한 관심사와 가장 높은 카테고리 하나를 기준으로 고른다.
- 카테고리는 `다큐멘터리 사진`, `예술사진`, `광고사진`, `영상과 기술(AI·편집·드론)` 네 가지다.
- 텍스트와 그래픽은 선택 화면의 단색 선형 그래픽 언어를 재사용한다. 새로운 사진 자산이나 AI 생성 이미지는 사용하지 않는다.

## 함께 연결되는 전문분야

실제 연계 겸임교원이 있으면 기존 교수 카드를 유지한다. 그 아래에 학생의 주 카테고리에서 파생한 전문분야 예시를 최대 3개 표시한다. 실제 연계 교원이 없더라도 빈 상태 문구 대신 전문분야 예시를 제공한다.

예시 카탈로그는 다음 방향을 따른다.

- 다큐멘터리 사진: 인터뷰·구술기록, 지역문화 아카이브, 포토스토리 편집
- 예술사진: 개인 창작 리서치, 사진·영상 설치, 포토북·전시 구성
- 광고사진: 제품·패션 촬영, 스튜디오 조명, 브랜드 이미지 기획
- 영상과 기술: 영상편집·색보정, AI 이미지·영상, 드론·360 콘텐츠

각 카드는 선형 그래픽, 분야명, 한 문장 설명만 갖는다. 사람이나 담당 교수를 확정하는 표현은 쓰지 않는다.

## 작품·포트폴리오 예시

검증된 학생 작품과 별도로 `이 경로에서 만들어볼 수 있는 예시` 영역을 제공하고 최대 3개를 표시한다. 실제 학생 작품 데이터가 있어도 예시 영역은 유지하되, 검증 작품보다 시각적 위계를 낮춘다.

- 다큐멘터리 사진: 인물 인터뷰 포토에세이, 지역 기록 사진집, 공공 아카이브 프로젝트
- 예술사진: 개인 주제 사진 연작, 사진·영상 설치전, AI 이미지 실험 포트폴리오
- 광고사진: 제품 광고 이미지, 패션·뷰티 화보, 브랜드 캠페인 포트폴리오
- 영상과 기술: 시네마틱 단편, 촬영·편집 쇼릴, 드론·AI 융합 영상

카드는 선택창과 같은 선형 그래픽을 사용하고 `예시` 배지를 표시한다. 출처일·실명·확정 진로처럼 검증 사실로 오인될 필드는 넣지 않는다.

## 학과 기반 표시 순서

초기 화면에는 다음 순서로 최대 3개만 표시한다.

1. 학생 관심과 가장 관련성이 높은 검증 시설 1개
2. 관련성이 높은 검증 카메라 바디 1개
3. 관련성이 높은 검증 렌즈 1개

시설 후보는 컴퓨터실, 스튜디오 A(호리존), 스튜디오 B, 암실 등 검증된 공간이다. 영상 편집·AI·후반작업은 iMac 2020 및 RTX 4080급 워크스테이션이 있는 컴퓨터실을 우선하고, 스튜디오 촬영은 스튜디오 A 또는 B, 흑백·필름 작업은 암실을 우선한다.

카메라·렌즈는 검증된 재고와 관심 태그가 모두 일치하는 항목만 고른다. 바디나 렌즈가 없으면 다른 장비로 억지 대체하지 않고 존재하는 유형만 표시한다. 나머지 관련 시설·기자재는 `학과 기반 더보기`로 펼친다.

장비 유형을 제목 문자열로 추측하지 않는다. 새 결과에는 검증된 기자재 원본의 `category`를 선택적 표시 메타데이터로 함께 저장한다. 기존 결과에는 이 필드가 없을 수 있으므로 `primaryTag`가 정확히 `camera` 또는 `lens`인 경우에만 호환 분류하고, 나머지는 기타 장비로 둔다.

## 교육환경 연결도

교육환경 연결도는 전체 콘텐츠 카탈로그의 채움 정도가 아니라, 선택한 경로를 실행할 핵심 조건이 검증되어 있는지를 나타내는 100점 만점의 준비도 점수로 바꾼다. 존재하지 않는 비교과·작품 레코드를 0점으로 넣어 점수를 낮추지 않는다.

- 관련 검증 시설 1개: 35점
- 관련 검증 카메라 바디: 15점
- 관련 검증 렌즈: 15점
- 학년별 관련 교과: 학년당 6.25점, 최대 25점
- 활성 총괄교수 연결: 10점

따라서 관련 시설, 카메라, 렌즈, 4개 학년 교과, 총괄교수가 모두 확인되면 100점이다. 누락된 검증 근거는 해당 점수만 제외한다. 예시 전문분야와 예시 포트폴리오는 점수에 포함하지 않는다. 결과는 소수 첫째 자리에서 반올림하고 0~100 범위를 보장한다.

새 결과는 저장 전에 이 규칙으로 계산한다. 기존 저장 결과는 조회 시 저장된 시설·장비·학습경로·교수 스냅샷으로 같은 점수를 다시 계산해 화면과 이력에 표시한다. 원본 검증 근거가 없는 과거 결과에는 점수를 임의로 보충하지 않는다. 데이터베이스의 사용자 정보나 선택 응답은 변경하지 않는다.

## 컴포넌트와 데이터 흐름

- 공유 예시 카탈로그가 네 카테고리별 전문분야·포트폴리오 카드와 그래픽 키를 제공한다.
- 결과 타임라인은 `rankedTracks[0]`을 예시 카탈로그에 전달한다.
- 교수진 영역은 검증된 실제 교수 카드와 전문분야 예시를 분리 렌더링한다.
- 결과물 영역은 검증 작품과 포트폴리오 예시를 분리 렌더링한다.
- 새 결과의 장비 표시 메타데이터는 검증 원본의 선택적 `category`를 포함하고, 기존 결과 스키마와 하위 호환된다.
- 학과 기반 컴포넌트는 시설·카메라·렌즈를 별도 그룹으로 정렬하며 시설을 먼저 렌더링한다.
- 서버는 저장 전에 검증 리소스와 4년 학습경로, 총괄교수 연결을 이용해 교육환경 준비도 점수를 계산한다.

별도 API, 데이터베이스 마이그레이션, 관리자 입력 필드는 추가하지 않는다.

## 오류와 빈 상태

- 알 수 없는 카테고리는 네 카테고리 공통의 탐색 예시 세트를 사용한다.
- 검증 시설이 없으면 시설 영역에서 학과 확인 안내를 표시하고 점수를 부여하지 않는다.
- 검증 바디·렌즈가 없으면 해당 유형을 숨기고 점수를 부여하지 않는다.
- 예시 카탈로그 오류는 결과 API 실패로 확대하지 않고 공통 예시로 대체한다.

## 테스트와 완료 기준

- 단위 테스트에서 네 카테고리가 각각 정확히 3개의 전문분야·포트폴리오 예시를 반환하는지 확인한다.
- 점수 테스트에서 시설·바디·렌즈·4개 학년·총괄교수가 모두 있으면 100점, 각 근거가 빠지면 정해진 점수만 감소하는지 확인한다.
- 컴포넌트 테스트에서 예시 라벨, 그래픽, 검증 콘텐츠와의 구분, 시설 우선 순서를 확인한다.
- E2E에서 광고사진 경로에 스튜디오가 먼저, 카메라와 렌즈가 뒤에 표시되는지 확인한다.
- 영상과 기술 경로에서 컴퓨터실이 우선되고 영상·AI 전문분야와 포트폴리오 예시가 표시되는지 확인한다.
- 모바일 390px에서 가로 스크롤이 없고 키보드 포커스와 44px 터치 영역을 유지한다.
- 기존 결과 조회·상담·관리자 내보내기 스키마는 유지한다.
