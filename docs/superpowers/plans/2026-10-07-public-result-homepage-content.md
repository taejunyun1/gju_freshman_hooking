# 공개 결과 화면 — 학과 홈페이지 콘텐츠 재사용

## 범위

로그인 없는 `/explore` 결과에만 적용한다. 기존 학생·관리자 화면, 추천 점수와 교과·교수 배정 로직, DB 및 상담 전송 계약은 변경하지 않는다.

## 화면 구성

1. 관심 분야의 짧은 소개와 실제 학과 사진
2. 기존 추천 스냅샷의 1–4학년 교과를 한 번만 표시. 전공필수 배지 유지. 교과 설명은 학년별 펼쳐보기
3. 분야별 홈페이지 활동 사례 2개. 기존 개인화 프로젝트 최대 3개는 별도 펼쳐보기
4. 상담 바로가기
5. 기존 전임교수 추천 2명과 작은 겸임·강사 카드 최대 2명
6. 분야별 홈페이지 졸업생 인터뷰 2명
7. 시설·기자재와 응답 점수·추천 근거는 기본 닫힌 상세 영역
8. 기존 상담 양식

홈페이지 사례와 개인화 추천은 구분한다. 공개된 활동을 미래 참여 보장으로, 졸업생 사례를 학생의 진로 보장으로 표현하지 않는다. 커리큘럼은 홈페이지 정적 루트로 대체하지 않고 `snapshot.learningPath`를 사용해 혼합 관심과 영상 2순위 4학년 추천을 보존한다.

## 콘텐츠 원본 (2026-10-07 확인)

읽기 전용 원본 저장소: `학과 홈페이지/gjuphoto`.

- `src/pages/index.astro`, `src/pages/curriculum.astro`: 분야별 소개, 영상 실습·전시·조명 교육 사진
- `src/data/campusActivities.ts`: 2026 광주 에이스페어, 프로젝션 맵핑 수업, 「사진의 얼굴」 GV, 5·27 새벽광장
- `src/pages/events/onbit-2026.astro`: 온빛다큐멘터리 워크숍
- `src/data/alumniInterviews.ts`: 박래현·임승찬 / 정한결·김윤교 / 신희수·판영석 / 이영은·윤동규 인터뷰
- `src/pages/faculty.astro`: 교수진 원본 사진. 사진이 없는 인물은 다른 사람의 사진으로 대체하지 않는다.

`shared/content/public-department-stories.ts`가 분야별 노출 콘텐츠, 원문 링크, 원본 이미지 URL을 관리한다. 이 목록은 자동 동기화가 아닌 날짜를 명시한 편집 스냅샷이다. 학과 홈페이지 콘텐츠가 변경되면 이 목록과 정적 사진 복사본을 함께 갱신한다.

사진은 원본 저장소 `public/uploads`에서 선정한 27개 WebP를 변경 없이 `public/images/gjuphoto`로 복사했다. 전체 자산 약 3.64 MB이며, 한 결과에서는 해당 분야와 추천 교수의 일부만 사용한다. 하단 사진은 지연 로딩하고, 이미지 전체 비율을 유지한다. 외부 API 호출·추가 DB 조회·동기화 서비스·새 패키지는 추가하지 않는다. CSP의 동일 출처 이미지 정책을 유지한다.

## 검증

- 공개 결과 컴포넌트 테스트: 개인화 4년 교과 보존, 전공필수 배지, 강사 최대 2명, 접힌 상세, 분야별 사진 파일·공식 링크, 공개 화면 범위 검사
- 전체 단위·통합 테스트 및 타입 검사
- 실제 공개 설문 → 결과 생성, 데스크톱·390px 모바일, 상세 펼치기, 사진 로딩과 원문 링크 점검
- 상담 수신 주소 확인은 기존 보류 상태 유지. 이번 변경으로 이메일 전송을 활성화하지 않는다.
